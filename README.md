# Portfólio Profissional de Jonatas Lazarini Guerra 🚀

Website de portfólio profissional de alta performance, responsivo e interativo, desenvolvido com foco em conversão comercial, apresentação de competências técnicas, experiência internacional e captação de clientes para a **AODEV Solutions**.

---

## 📁 Estrutura do Projeto

```
jonatas-portfolio/
│
├── index.html                  # Página principal com arquitetura semântica HTML5 e Schema.org JSON-LD
├── css/
│   └── style.css               # Folha de estilos moderna (Dark/Light mode, Glassmorphism, CSS Grid & Flexbox, Print CSS)
├── js/
│   └── script.js               # Lógica interativa: Gráfico Radar Chart.js, Analytics Tracker, Downloads e Formulários
├── assets/

│   ├── favicon.svg             # Ícone SVG personalizado de alta fidelidade

│   └── resume_jonatas.txt      # Currículo limpo em formato texto puro (.txt) para ATS
└── README.md                   # Documentação completa do projeto
```

## 🎯 Seções do Portfólio

1. **1 – Resumo Profissional**
   - Apresentação destacando a transição internacional Brasil-Portugal, principais especializações (Front-end, Informática Avançada, Excel e Gestão Fiscal) e metas de carreira.
2. **2 – Experiência Profissional**
   - Linha do tempo interativa cobrindo a atuação na **AODEV Solutions** (Leiria, Portugal), **Artemil** (Pataias, Portugal), **Palácio das Ferramentas e Parafusos** (Franca, Brasil), **Rex Auto Detailing**, **EVASOFT** e **L. E. N. de Souza**.
3. **3 – Formação Acadêmica**
   - Ensino secundário completo, capacitação em desenvolvimento web (HTML5, CSS3, JavaScript, Java básico), Microsoft Excel avançado, competências linguísticas e habilitação (Cartas A2, A e B).
4. **4 – Competências e Habilidades**
   - Gráfico de Radar interativo (via Chart.js) com alternância entre "Todas as Competências", "Técnicas" e "Comportamentais (Soft Skills)", acompanhado de barras dinâmicas de progresso.
5. **5 – Detalhamento das Experiências**
   - Destaque aprofundado com cases reais:
     - Plataforma oficial da construtora **Junio DSL** (`juniodsl.com`);
     - Hub de transformação digital **AODEV Solutions** (`aodev.solutions`);
     - Otimização operacional e emissão de notas fiscais industriais.
6. **6 – Formulário de Contato**
   - Formulário inteligente com seleção de serviços e botão integrado para disparo direto via **WhatsApp** ou e-mail corporativo.
7. **7 – Integração com Redes Sociais**
   - Conexão direta com Instagram (`@jonxtas_`), WhatsApp, LinkedIn, GitHub e AODEV Solutions.
8. **8 – Download do Currículo**
   - Menu suspenso para baixar o currículo em múltiplos formatos: **PDF** (via impressão otimizada de alta resolução), **Word (.doc)** e **Texto puro (.txt)**.

## ⚡ Recursos Técnicos & Diferenciais

- **Otimização de Performance:** Zero bibliotecas desnecessárias, tempo de carregamento instantâneo, renderização veloz.

- **Roadmap de Carreira & Pipeline:** Quadro interativo com metas concluídas, em andamento e planejadas para 2026/2027.

## 🌐 Como Executar Localmente

Como o projeto é construído em HTML5, CSS3 e JavaScript moderno puro, você pode abri-lo diretamente:

1. **Abertura Direta:**
   - Dê um duplo clique no arquivo `index.html` para abrir em qualquer navegador (Chrome, Edge, Firefox, Safari).

2. **Servidor Local via PowerShell (opcional):**
   ```powershell
   cd "C:\Users\Administrator\.gemini\antigravity\scratch\jonatas-portfolio"
   # Ou abrir diretamente no navegador padrão:
   Start-Process "index.html"
   ```

3. **Publicação com 1 Clique (Deploy):**
   - **GitHub Pages:** Suba os arquivos para um repositório GitHub e ative o GitHub Pages nas configurações.
   - **Vercel / Netlify:** Arraste e solte a pasta `jonatas-portfolio` para publicação instantânea com certificado SSL e CDN global.
